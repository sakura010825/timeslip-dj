# ショート用「新しい語り」4本（N1〜N4）

作成日 2026-10-01。原稿係の成果物。リポジトリのファイルは触っていない。音声化（TTS）とレンダは次の係。

## 先に読むところ

- 4本とも、第1文は人名・グループ名から始め、動きのある記録か意外な組み合わせを1つ、当時の感覚を1つ入れ、最後は余韻で終えた。歌詞の引用はなく、事件・事故・災害にも触れていない。
- 事実は全部ネットで裏取りした（出典URLは各本の表）。裏が取れなかった言い回しは使わず、各本の「使わなかった言い回し」に残した。
- 「字幕用」と「読み上げ用」は文の区切り（。と、）を同じにしてある。違うのは表記だけ（漢字→かな、数字・英字→読み、%→パーセント）。例外は N4 の1文目で、字幕の「モーニング娘。」の「。」は名前の一部（読み上げ用は「モーニングむすめ」）。
- 長さは本編の文字起こしから測った。目安は「1秒に約4.2字（漢字かな交じり・句読点なし）」だが、年や%などの数字は読みが長くなるので、字数ではなく「拍（かなの数）」で見積もった。見積もりは各本 27〜29秒、誤差はおよそ±1.7秒。**TTSで実測して、長ければ各本の「長いとき」、短ければ「短いとき」の手当てをする。**
- **年の書き方（指示との違い）**: 読み上げ用では年を算用数字ではなく**かな**にした（例 せんきゅうひゃくきゅうじゅうろくねん）。理由は、`timeslip-dj/lib/tts-pronunciation-dict.ts` に「文頭の『1986年の春』を『にせんきゅうひゃく…』と誤読」という実例があり、4本とも2文目の頭（N2は4文目の頭にも）に年が来るため。算用数字のままにしたい場合は JSON の `tts_text_digit_years` を使う。ほかの数字（36.7・32・18日・13歳・4番・1位・3週）は、公開済みの本編の台本で使われている書き方（30.8パーセント・41.3パーセントなど）なので算用数字のまま。
- 人名の読み: 既存の読み辞書にない名前は、かな＋中黒（例 すずき・ほなみ）にした。辞書にある山口智子・鈴木保奈美も、辞書に頼らずかなにしてある。木村拓哉だけは、本編の公開音声（1998秋・1999冬）で使われていて実績があるので漢字のまま。読みの確認: おニャン子クラブ（おニャンこクラブ）・新田恵利（にった えり）・織田裕二（おだ ゆうじ）・小田和正（おだ かずまさ）・後藤真希（ごとう まき）は日本語版Wikipediaの冒頭の読みで確認、山口智子・鈴木保奈美は読み辞書（9/17にWikipedia・コトバンクで確認済み）。
- 年の見せ方: 3本目（東京ラブストーリー）は放送が1991年1月なので音声・題名・コメントは「1991年」、サイトの回は1990年・冬（12月〜2月）なのでIGの最後の1行だけ「1990年・冬」。
