## 🔄 2026-07-30 改訂: Xは「中の人」名義に変更した

**シンヤ名義をやめた。理由はフォロワー0だからではなく、Xが要求するものをシンヤが構造的に
持てないから。** Xで伸びるのは時事・他人の投稿への**反応**だが、シンヤは1985〜2000年の
DJという設定なので2026年の話題に反応できない。反応すれば設定が壊れ、反応しなければ配られない。

- 表示名 `ReDial｜あの季節の深夜ラジオ`／ハンドルは `@redial_shinya` のまま（3面で統一）
- **語るのは「開発記録」ではなく「当時の話」**。開発記録だと個人開発クラスタ（20〜40代の
  作り手）が集まり、それは顧客ではない。hideさんは1972年生まれ＝ReDialの中心（1988〜1995）が
  そのまま10代後半〜20代前半なので、当時の話は**実体験**になる
- **投稿よりリプライが主**（0フォロワーが見られる経路は事実上リプライだけ）。
  投稿は「リプライで得た関心の受け皿」＝プロフィールに来た人が見て動いていると分かるため
- ハッシュタグは**付ける**（改訂）。ただし**年＋題材の固有名詞**のみ。`#平成レトロ` は使わない
- 名義まわりの正 = `redial/docs/`（`reference_sns_accounts_and_surfaces` 相当）

### 制作フロー（2026-07-30 確立）

```
Claude: 7月／夏に日付が立つ題材を3つ提示（KBから拾い、日付はWebSearchで検証）
  ↓
hide:   それぞれに「記憶の断片」を断片のまま話す（無い題材は「無い」と言う）
  ↓
Claude: hideさんの言葉を軸に140字（=280 units）に組み、文字数を実測して渡す
```

**🚫 記憶が無い題材で書かない。**これがこの方式の唯一の原則。作文すると演技になり続かない。

### 🎯 締めの問いの原則（hide指摘 2026-07-30）

**その投稿が立てた枠の中で答えられる問いにする。年を跨がせない。**

型C（走馬灯）の定型 `あなたの◯は、何年ですか` は、「ぜんぶ1993年の秋です」と
**先に「年は複数ある」枠を立ててから**問うので成立する。ところが1つの年を語る投稿で
これを使うと、**読者をさっき入った枠から出してしまう**（hideさん「ピンとこない」）。

✅ `1990年の夏、あなたは何をしていましたか。`
❌ `あなたの夏は、何年ですか。`

**さらに重要**: 「その年のその季節に何をしていたか」を思い出させる問いは、
**そのままReDialの体験（年×季節を編む）への入口になる**。
問いは会話のためだけでなく、**導線の入口として設計する**。

**答えやすさ＝返信数**。「何を聴いていましたか」より「何をしていましたか」のほうが、
曲を思い出せない人も答えられるので広く拾える。カラオケの話なら
「カラオケでよく歌ったのは何でしたか」のように**投稿が立てた枠の中で**聞く。

## 🔄 2026-07-31 改訂: 運用の実践形が確定した（3日分の初運用で）

### ハッシュタグは付けない（7/30改訂を再改訂）

7/30に「年＋固有名詞のタグは付ける」としたが、**初の連続運用で「付けない」に確定**。
理由: 中の人名義の投稿は「個人が自分の記憶を書いている」体裁であり、実際に人が思い出を
書くときタグは付けない。**付いた瞬間に宣伝アカウントの匂いがして、記憶の話が営業に見える**。
タグが発見経路として機能するのは作品面（YouTube/Instagram）の話で、人面のXでは
文字数を食うだけ。リンクを置かない判断（コールドスタート期）も継続。

### 推敲の3原則（2026-07-31 実運用の失敗から）

1. **hideさんの感情語を、自分の言葉に置き換えない**。「可愛くもあり微笑ましくもあり」を
   「その『今まで』の短さに笑って」と要約したら、**20歳が14歳を見下す文**に反転した
   （「笑う」は対象を下に置く動詞にもなる）。感情語は本人の語をそのまま使う
2. **事実誤認は連鎖する**。「助手席→ハンドルを握って」と直すとき、前行の「誰かの車の
   カーステ」も直さないと「他人の車に乗せてもらっていた」絵が残る。1箇所直したら
   その事実に依存する行も洗う
3. **自分の年齢は書かない方が強いことがある**。「こっちは20歳。」を削ったら感情だけが
   残って素直になった。中の人の情報は感情が伝わる最小限でよい

### リプライ運用の型（毎晩22時前後の10分・投稿より主）

```
タイムラインを上から眺める
  → 当時の話をしている投稿に「最初の葉書」を1〜2件
  → 型 = 相手の記憶に自分の記憶を並べる＋具体1つ＋1〜2行
  → 迷ったら いいね だけ。判断に迷う投稿はスクショをClaudeへ
```

- 🚫 **売り込まない・リンクを貼らない・アドバイスしない・議論しない**。
  「懐かしいですね」だけの返信もしない（誰でも書ける＝具体が無いと同世代と伝わらない）
- **鮮度が命**: 相手の投稿から1時間以内が最も効く。まとめてやる運用は成立しない
- **金脈はフォロー中のハブのリプ欄**: きりぼー（@kiribo0111・ザ・ベストテン映像
  アーカイブ・1投稿いいね3,000）と 90年代J-POP BAR MYLIFE（@90sjpopbarmylif・
  問いかけ投稿で会話が生まれる）。**この2つの投稿がTLに出たらリプ欄に1件置く**
- API自動化は見送り（他人の投稿読み取り$0.005/件≒月$9・鮮度問題が解決しない・
  リプライ戦略自体が未検証）。**1週間回して返信/フォロワー/プロフクリックを見てから再判断**

| 項目 | 値 |
|---|---|

| 時刻 | 22時前後（深夜ラジオの気配が立つ時間・MARKETING_FUNNEL §4） |
| 動画 | **X にネイティブアップ**（同じ mp4 を使い回す） |
| リンク | **本文に置かない。自己リプに置く** |
| ハッシュタグ | 付けない（Xでは拾われにくく、本文の余白を削る） |
| 返信 | ハートのみ（会話に降りない＝深夜ラジオの距離感） |

### なぜリンクを自己リプに置くのか
本文にリンクを入れると、Xはその投稿のリーチを 30〜50% 落とす。
「Xだと伸びない／Threadsのほうが」と言われるものの正体はこれ。
本文は本文だけで完結させ、リンクはぶら下げる。

### リプは3パターンを回して数字で決める
末尾の `-r1 / -r2 / -r3` で landing 側が見分けられる（`/admin` の「流入（landing・UTM）」）。
**1投稿につき1パターン**。同時に並べるとどれが効いたか分からなくなる。

| | 型 | ねらい |
|---|---|---|
| r1 | 宛先だけ | いちばん短い。基準線 |
| r2 | 中身を訴求 | 「このあと何が起きるか」を書く |
| r3 | 自分ごとに寄せる | 「あなたの◯年」と問い返す |

## 投稿後に読む数字

`npm run ops`（redial側）の「2b. 流入（landing・UTM）」に
`x/reply/<セル>-<型>-<r番号>` が出る。出なければ**誰も押していない**。

読む順番:
1. そもそも landing が増えたか（＝リンクが押されたか）
2. r1 / r2 / r3 のどれが押されたか
3. 型A と 型B のどちらが押されたか

3〜5本ぶん回してから比べる。1本では何も分からない。
