## 0. 先に結論（要点だけ）

1. **YouTube で配られるかどうかは、最初の1〜2秒で見続けられた割合（継続%）でほぼ決まる。** 継続%が26%以上の弾は43本中41本が48時間で800回以上に届き、18%未満は24本中2本だけ（見出し札の時代＝8/18以降に絞ると、26%以上は39本中38本、18%未満は14本中0本）。
2. 継続%を上げていたのは「**人名・団体名で入る題**」と「**音楽・TV**」。見出し札の時代（8/18〜）の初出57本で、人名で入る弾は25/34（74%）が配られ、それ以外は9/23（39%）。音楽かTVは21/28（75%）、それ以外は13/29（45%）。
3. 「物・制度・出来事の説明」から入る弾は弱い。社会・流行語 2/7、商品・道具 1/4、ゲーム 1/3、スポーツ 2/5、（個人選手の回は0/4）。継続%は18〜20%前後で止まる。
4. **維持率は尺で決まる。** 平均視聴秒は尺に関係なく17〜20秒。34秒以下は維持率63〜68%・配られた率74%、35秒以上は維持率43〜46%・配られた率47%。
5. **見出し札は効く。** 札なしの初出を「同じ音声＋札つき」で別ファイルに作り直した15組は、継続%の中央値が+12.8pt（12組で上昇）。止まっていた9本のうち6本が配られた。同じファイルの再アップは3本とも悪化（48時間の再生 2,436〜2,745 → 292〜627）。
6. 朝/夜、型A/B、題名の数字、見出しの行数、題材の年、曜日は、差が偶然の範囲。
7. 時期（8月→9月）: 配られた率は8/18〜8/31の40%から9月の60〜67%へ上がった。中身は「人名で入る題」が30%→65〜67%、尺の中央値が39秒→38秒→33秒。一方、配られた弾の48時間再生は 7/24〜8/11 の中央値2,080から、8/12以降は約1,050〜1,100（最大1,418）に半減したまま戻っていない。
8. 最近の差（失楽園・B'z『MOTEL』が強く、ジュラシック・パーク・2000円札・そごう・ミスチルが弱い）は B-7。人名が先頭かどうか・物や出来事の説明か・尺・札が「情景だけ」か、で説明がつく。ただしジュラシック・パークの「48時間で2回」は題材の弱さでは説明できない配信ゼロで、原因は分からない。
9. Instagram は リーチの中央値が102。YouTube の当たり外れとほぼ無関係（相関0.12）で、平均視聴秒に付いていく（相関0.65）。跳ねた4本（クリスマス・イブ4,480／ちびまる子ちゃん1,069／チェッカーズ875／メンズノンノ326）のうち3本は2日目に伸びた。
10. 来週の題材選びの基準・もう一度扱う価値がある題材・避ける型は **D**。「①人名・団体名で入る ②音楽かTV ③尺34秒以下」の3点採点で、2点以上は29本中24本（83%）が配られ、0〜1点は28本中10本（36%）だった（結果を見てから選んだ項目なので、来週の16本で検証する前提）。

## 1. 読み方（定義と限界）

- **分類**（音楽／TV／映画／スポーツ／ゲーム／商品・道具／社会・流行語／その他）と**題名の先頭**（人名・団体名／作品名／物・現象・場所／数字・一般語）は、私が題名と見出しを読んで**事後に手で付けた**。境界があいまいな題材（たまごっち＝商品・道具、2000円札＝商品・道具、失楽園＝社会・流行語、慎吾ママ＝社会・流行語、サラダ記念日・メンズノンノ＝その他 など）には理由を `perf-table.json` の `label_note` に書いた。
- **配られた／止まった／ほぼ出ず**: 公開から48時間の再生が800以上／100〜799／100未満。48時間の分布は二山で、650〜830にほぼ空白があるのでそこで割った。
- **継続%** = Analytics の「スワイプせず見た回数÷再生」（Studio の「視聴を継続」に近い）。**維持率** = 平均視聴率。100%を超える値は短尺のループで、比較に使わない（表では ↻）。公開から3.5日未満の弾は確定前なので、継続%・維持率の集計から外した。
- **24h／48h／7日**: 毎朝6:27の累計をつないだ推定値。朝07:00公開の弾は最初の収集が約23.5時間後なので実測にほぼ一致。夜22:00公開の弾は収集が8.5／32.5／56.5時間後なので直線で補間した推定（本当の24時間値はやや高い可能性）。
- **初出** = 同じ話（同じ窓）を初めて出した回。**札の時代** = 見出し札を付け始めた8/18以降。特に断らない限り、比較は「札の時代の初出57本（48時間が来ているもの）」で行う。
- **型A** = 曲を予告しない。**型B** = 曲を予告して切る。型Dは「トーク→曲」の別カット（3本）、型Cは走馬灯デモ（1本）。
- 本数が少ない所は本数で書き、断定しない。「偶然で出る確率」は小さいほど偶然では説明しにくい（0.05未満が目安）が、何項目も調べているので0.03前後は「有力な手がかり」止まり。

### B-3. 何が「維持率」を分けたか

- **平均視聴秒は尺に関係なく17〜21秒**（尺26〜44秒のどの帯でも中央値17〜21秒。札の時代の初出では17〜19.5秒。尺と平均視聴秒の相関0.11）。だから維持率はほぼ「18秒÷尺」になる。
- 札の時代の初出で、維持率の中央値は 尺29秒以下 68%（9本）／30〜34秒 63%（13本）／35〜39秒 46%（11本）／40〜44秒 43%（8本）。45秒以上の4本だけ70%だが、ちびまる子ちゃん（46秒・継続41.5%）と鈴木大地（47秒・継続44.1%）のように入口が極端に強い弾が引き上げていて、例外。ループ（100%超）を除いた全投稿（約88本）で見ると、26〜34秒 63〜65%／35〜39秒 41%／40〜44秒 49%／45秒以上 38%で、同じ向き。
- 人名で入る題は維持率63%、それ以外38%。音楽/TVは64%、それ以外43%。継続%が26%以上の弾は65%、未満は46%（継続%と維持率の相関0.49）。
- 7/30に立てた仮説「維持率は尺で割れる（30秒台以下が高い）」は、110本に増えても崩れていない。ただし割れ目は「30秒」より「35秒」に近い。

### D-1. 選ぶ基準（8つ）

1. **入口は人名・団体名にする**（歌手・グループ・俳優・番組の顔・チーム）。札の時代の初出で、人名先頭は25/34（74%）が配られ、それ以外は9/23（39%）。物・出来事・作品名しか無い題材は、その顔（出演者・歌手・選手）を札の1行目に置き直せる場合だけ選ぶ。（9月だけに絞ると71%対50%で、確かさは落ちるが向きは同じ。）
2. **音楽とTVを軸にする**（21/28＝75%、それ以外は13/29＝45%）。ドラマは**主演・出演者の名前**で入る（6/7。作品名で入ると2/4）、映画は**俳優・監督の名前**で入る（3/3。作品名で入ると2/5）。16本のうち10〜12本をここに置くのが目安。
3. **尺は34秒以下**（74%対47%。9月だけなら83%対46%）。平均視聴秒は約18秒で尺に関係なく一定なので、35秒を超えると維持率が63〜68%から43〜46%に落ちる。40秒以上は下位20のうち9本。
4. **札は「誰が」＋「意外な並び・逆説・動きのある記録」を1行目から**。上位20は光GENJI／初登場1位、ブリトニーと倉木麻衣が同じ冬、KKでも届かなかった、のような形。下位20は「世界初の／最後の〜版／日本では／平均視聴率」のような事実の紹介、または情景だけ。音楽の札は記録・意外な事実・問いが11/11、情景・動作だけが2/6（事後の分類）。

7. **初期の札なし弾は、札を付けて作り直す価値がある（音楽・人名の題材に限る）**: 15組で継続%+12.8pt・止まっていた9本中6本が配られた。商品・道具（ポケベル・ダイヤルアップ）は復活しなかった。

### D-3. 避けるべき題材の型

1. **物・制度・技術・出来事の説明で入り、人を先頭に置けないもの**（ベルリンの壁・2000年問題・新人類・冷房停電・Windows 95・タピオカ・プリクラ・ダイヤルアップ・ポケベル・2000円札・そごう・ビッグエコー）。物・現象・場所で入る弾は4/10、社会・流行語は2/7、商品・道具は1/4。継続%は18〜19%で止まる。
2. **札が事実の紹介だけ**（「世界初の」「最後の〜版」「日本では〜」「平均視聴率○%」）。トイ・ストーリー204・ドラクエ4 240・マライア211・武田信玄221。数字は「キムタクとB'zの冬」のように意外な並びと組んだときだけ効いた。
3. **個人のスポーツ選手の事実**（野茂599・セナ159・中田英寿314・高橋尚子179）。
4. **ゲーム（特にドラクエ）**（343／240。視聴者が55歳未満の男性に寄る）。波動拳は7/31に2,080、9/5の札版に1,049で配られたので全否定ではないが、札の時代の初出では1/3（PS2だけ配られた）。
5. **CG・技術の驚きで入る映画**（トイ・ストーリー・ジュラシック・パーク）。
6. **情景・動作だけの音楽札**（ゲレンデへ向かう冬・止まらないステップ・リーゼントを真似した春・リフト40分待ち＝4本とも止まり）。事後の分類なので「避ける」より「記録・意外・問いに言い換えられるか確認する」。
7. **40秒以上の尺**（40〜44秒は5/13のみ配られた）。
8. **同じ話を同じファイルで出し直すこと**（3本とも沈んだ）。出し直すなら札を作り直して別ファイルで、音楽・人名の題材に限る。

### D-4. 来週16本の組み方の目安（提案）

- **10〜12本**: 人名で入る音楽・TV（歌手・グループ・主演名）。尺は27〜34秒。札は「誰が＋意外な並び/記録」。
- **2〜3本**: 人名で入れ直せる映画・スポーツ（俳優・監督・チーム・名勝負）。
- **1〜2本**: 探索枠（これまで弱かった分類を人名で入れ直す）。外れても1〜2本に抑える。
- **1〜2本**: 札なしの初期弾の札つき再レンダ（音楽・人名に限る）。

## 付録. 方法・検算・限界

- 材料: sns_metrics（YouTube 3,754行・Instagram 895行、select のみ）、YouTube Data API（117本のタイトル・説明欄・尺・今の再生）、YouTube Analytics API（動画別・累計。合計93,597回がチャンネル合計と一致）、sns_schedule（台帳idと動画IDの対応）、台帳 `shorts.manifest.json`（128件）。キー（鍵）は出力に書いていない。
- 台帳への対応: 予約表43本・campaign＋題名28本・手動39本（7/24〜8/24の台帳に campaign が無い時期と、9/1〜9/4の同一mp4再アップ）。題名と台帳を全件突き合わせ、食い違いは題名の後日変更2件（#21・#28）のみ。8/22〜8/31の朝組が札版（新レンダ）、9/2〜9/4の朝が同一mp4、9/1の卒業は「同一mp4の可能性が高い」が確証なし。
- 推定の限界: 24h/48h/7日は直線補間で、夜公開の弾は実際よりやや低めに出る。継続%・維持率は公開3.5日未満を除外。維持率の100%超（7本）は比較から外した。Instagramは8/5〜9/3の投稿の初日値が無い。
- 統計の限界: 札の時代の初出は57本、分類別は3〜17本。分類と題名の先頭は事後に手で付けたもので、結果を見たあとの後付けの要素がある（特に「情景・動作／記録・意外」の札の分け方）。20項目近くを調べているので、偶然の確率0.01〜0.05の差は「有力な手がかり」として扱い、来週の選び方で確かめる前提にする。
- 配信ゼロ（DEPARTURES・ジュラシック・パーク）の原因: Data API の状態（公開・埋め込み可・権利申し立てなし・地域制限なし）に異常はなく、特定できなかった。
- 台本の在庫（未使用の窓）は確認していない。
